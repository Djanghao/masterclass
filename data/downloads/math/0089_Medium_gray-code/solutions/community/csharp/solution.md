# Intuition
The intuition is to either use `recursion` or `reflecting the list and prefixing the reflected codes with 1` and the property of Gray code that the `n`-bit Gray codes can be generated from the list of `(n-1)`-bit Gray codes.

# Approach 1
1. **Base Case**: 
If `n` is `1`, the code returns a list containing `0` and `1`, which are the Gray codes for `n = 1`.
2. **Recursive Case**: 
If `n` is greater than `1`, the code calls itself with `n - 1` to get the list of `(n-1)`-bit Gray codes (`code`).
3. **Generate n-bit Gray Codes**: 
The code then creates a new list `ans` and adds all elements of `code` to `ans`. After that, it iterates over `code` in reverse order and adds each element plus the count of elements in `code` to `ans`. This is based on the property of Gray code that the `n`-bit Gray codes can be generated by reflecting the list of `(n-1)`-bit Gray codes and prefixing the reflected codes with `1`.
4. **Return Gray Codes**: 
The code returns `ans`, which contains the `n`-bit Gray codes.

# Code
```
public class Solution {
    public IList<int> GrayCode(int n) {
        if(n == 1)
            return new List<int>() {0, 1};
        
        IList<int> code = GrayCode(n - 1);
        IList<int> ans = new List<int>();

        for(int i = 0; i < code.Count(); i++) {
            ans.Add(code[i]);
        }

        for(int i = code.Count() - 1; i >= 0; i--) {
            ans.Add(code[i] + code.Count());
        }

        return ans;
    }
}
```

# Approach 2
1. **Initialize Variables**: 
The code initializes a list `ans` with the Gray codes for `n = 1`, which are `0` and `1`.
2. **Generate n-bit Gray Codes**: 
The code then iterates over the range from `0` to `n - 1`. For each `i`, it reflects the current list of Gray codes (`temp`) and prefixes the reflected codes with `1` by adding the count of elements in `temp` to each reflected code. It adds the new codes to `ans`.
3. **Return Gray Codes**: 
The code returns `ans`, which contains the `n`-bit Gray codes.

public class Solution {
    public IList<int> GrayCode(int n) {
        List<int> ans = new List<int>() {0, 1};
        for(int i = 0; i < n - 1; i++) {
            List<int> temp = ans;
            int constant = temp.Count();
            for(int j = temp.Count() - 1; j>= 0; j--) {
                ans.Add(temp[j] + constant);
            }
        }
        return ans;
    }
}
