# Intuition
<!-- Describe your first thoughts on how to solve this problem. -->
>The problem requires us to find the number of profitable schemes that can be chosen with at most n members participating in them and the minimum profit of minProfit. A profitable scheme is any subset of crimes that generates a profit of at least minProfit and requires at most n members to participate in it.

# Approach
<!-- Describe your approach to solving the problem. -->
>One way to approach this problem is to use dynamic programming. We can define dp[i][j][k] as the number of schemes that can be chosen using the first i crimes, with j members and k profit. The final answer would be the sum of dp[N][j][minProfit] for all j from 0 to n, where N is the number of crimes.

>Then, we will fill the dp array using a recurrence relation. For each crime i, we have two options: either we include it or we don't. If we include it, we need to update the number of members and the profit generated. Otherwise, we can simply skip it.

>The recurrence relation for dp[i][j][k] can be defined as follows:

>dp[i][j][k] = dp[i-1][j][k] + dp[i-1][j-group[i-1]][max(0, k-profit[i-1])]

>The first term on the right-hand side corresponds to the case where we don't include crime i. The second term corresponds to the case where we include crime i. Note that we need to use max(0, k-profit[i-1]) to handle the case where the profit generated by crime i is greater than k.

>After filling the dp array, we can compute the final answer by summing up the values in the dp array that satisfy the constraints.

# Complexity
- Time complexity:
<!-- Add your time complexity here, e.g. $$O(n)$$ -->
>O(n * minProfit * N), where n is the maximum number of members, minProfit is the minimum profit required, and N is the number of crimes. We need to fill an N x (n+1) x (minProfit+1) dp array, which takes O(n * minProfit * N) time.

- Space complexity:
<!-- Add your space complexity here, e.g. $$O(n)$$ -->
>O(n * minProfit * N), where n is the maximum number of members, minProfit is the minimum profit required, and N is the number of crimes. We need an N x (n+1) x (minProfit+1) dp array to store the intermediate results.

```java []
    class Solution {
        public int profitableSchemes(int n, int minProfit, int[] group, int[] profit) {
        int MOD = (int)1e9 + 7;
        int N = group.length;
        int[][][] dp = new int[N+1][n+1][minProfit+1];
        dp[0][0][0] = 1;
        for (int i = 1; i <= N; i++) {
            int g = group[i-1];
            int p = profit[i-1];
            for (int j = 0; j <= n; j++) {
            for (int k = 0; k <= minProfit; k++) {
                dp[i][j][k] = (dp[i-1][j][k] + (j >= g ? dp[i-1][j-g][Math.max(0, k-p)] : 0)) % MOD;
                }
            }
        }
        int ans = 0;
        for (int j = 0; j <= n; j++) {
            ans = (ans + dp[N][j][minProfit]) % MOD;
        }
        return ans;
    }
}
```

```C++ []
        int MOD = 1e9 + 7;
```

```python []
class Solution(object):
    def profitableSchemes(self, n, minProfit, group, profit):
        MOD = 10**9 + 7
        
        length = len(group)
        dp = [[[0] * (minProfit + 1) for _ in range(n + 1)] for _ in range(length + 1)]
        dp[0][0][0] = 1
        for i in range(1, length + 1):
            members, earn = group[i - 1], profit[i - 1]
            for j in range(n + 1):
                for k in range(minProfit + 1):
                    if j < members:
                        dp[i][j][k] = dp[i - 1][j][k]
                    else:
                        dp[i][j][k] = (dp[i - 1][j][k] + dp[i - 1][j - members][max(0, k - earn)]) % MOD
        
        total = sum(dp[length][j][minProfit] for j in range(n + 1))
        return total % MOD
```
