**GENERATING  THE POWER ARRAY**
The power array can be generated by inserting the power of two at the set bit of the number N.
As that will sum up to become the value of N.
ex : 11 -> 1011 
The power array : 1(2^0) , 2(2^1) , 8(2^3).

**CALCULATING**
Once the power array is generated we can simply traverse on the queries list and calculate the answer in a brute force method.
```
class Solution {
public:
    vector<int> productQueries(int n, vector<vector<int>>& q) {
       
        vector<int> pow;
        long long mod = 1e9+7;
        
        //if bit is set insert in the power array
        for(int i =0;i<32;i++)
        {
            if(n&(1<<i))
                pow.push_back(1<<i);
        }
        vector<int> ans;
        
        //solving for the query
        for(int i =0;i<q.size();i++)
        {
            long long temp=1;
            for(int j =q[i][0];j<=q[i][1];j++)
            {
                temp=((temp%mod)*pow[j])%mod;
            }
            ans.push_back(temp);
        }
        return ans;
    }
};
```
**The mod part needs to be taken in consideration because it results in weird answer if not done properly. apply mod everytime you add or remove a element**
