# Approach
<!-- Describe your approach to solving the problem. -->

1. It first determines the length of the input array `nums` and creates a new integer array `arr` of the same length to store the result.

2. The code uses two pointers, `i` and `j`, to iterate through the input array `nums` and the result array `arr`, respectively. Initially, both pointers are set to 0.

3. The code enters a loop that iterates over the elements of the input array `nums`.

4. Inside the loop, it checks the current element `nums[i]`:
   - If `nums[i]` is equal to 0, it continues to the next iteration (skips the current element).
   - If `nums[i]` is not equal to 0, it checks whether the next element (`nums[i+1]`) is equal to the current element (`nums[i]`) and whether it's within the bounds of the array (`i < length-1`).
   
   - If both conditions are true, it means there's a pair of consecutive elements with the same value. In this case, it performs the following actions:
     - It doubles the value of the current element and stores the result in the corresponding position of the result array `arr` (i.e., `arr[j++] = 2 * nums[i]`).
     - It sets the next element (`nums[i+1]`) to 0 to indicate that it has been used in the operation.
     - It increments both `i` and `j` to move to the next elements in both arrays.
   
   - If the conditions are not met, it means the current element is not part of a pair with the next element, so it simply stores the current element's value in the result array `arr` (i.e., `arr[j++] = nums[i]`).

5. After processing all elements in the input array `nums`, the loop ends, and the result array `arr` contains the values after applying the specified operations.

6. The code returns the result array `arr` as the output of the `applyOperations` method.

In summary, this code processes an input array, doubles the values of consecutive equal elements, and returns a new array with the result of these operations, eliminating the intermediate zeros generated by the doubling operation.

# Code1
```Java
class Solution {
    public int[] applyOperations(int[] nums) {
        int length = nums.length;
        int [] arr = new int[length];

        for (int i = 0 , j = 0; i < length; i++)
        {
            if(nums[i] == 0) continue;
            
            if (i < length-1 && nums[i] == nums[i+1])
            {
                arr[j++] = 2 * nums[i];
                nums[++i] = 0;  // or i++;  only
            }else{
                arr[j++] = nums[i];
            }
        }
        return arr;
     }
}
```
