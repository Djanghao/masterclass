# 2019. The Score of Students Solving Math Expression

## Intuition

The problem asks us to evaluate the correctness of students' answers to a math expression and score them accordingly. The key insight is to use dynamic programming to generate all possible results of the given expression by considering every possible way to compute it, allowing for mistakes typically made by students, like ignoring the order of operations. This approach ensures we cover all potential answers a student might submit, given the constraints of the operations.

## Approach

1. **Dynamic Programming for Possible Results**: We use a dynamic programming technique to generate all possible results of the given expression. The `calc` function, which uses memoization through the `cache` function, computes the possible results for any substring of the expression by recursively breaking it down into smaller parts and combining their results according to the operation between them (`+` or `*`). This approach considers every possible way to parenthesize the expression, capturing potential student errors in order of operations.

2. **Correct Answer Calculation**: We separately compute the correct answer of the expression using the `calculate` function, which follows the standard order of operations (evaluating multiplication before addition) without any parentheses altering this order.

3. **Scoring**: The student's answers are scored by comparing them against the correct answer and the set of all possible answers generated by our dynamic programming approach. A correct answer gets the highest score, a plausible but incorrect answer (one that could result from a common mistake) gets a lower score, and an implausible answer gets no points.

4. **Memoization**: The `cache` function is a higher-order function that memoizes the result of the `calc` function to avoid recomputing the results for the same substring of the expression, improving the efficiency of our solution.

## Complexity

- **Time Complexity**: The time complexity is hard to determine precisely due to the dynamic nature of the problem. It depends on the number of possible intermediate results we can generate from substrings of the expression, which can be exponential in the worst case. However, memoization significantly reduces redundant computations, improving performance.

- **Space Complexity**: The space complexity is also influenced by the number of possible intermediate results, as we store these results and the cache for memoization. In the worst case, this could also be exponential relative to the length of the expression, but is typically less due to the limit on the value of results (`<= 1000`).

function scoreOfStudents(s: string, answers: number[]): number {
    const MAX = 1000;
    const calc = cache((start: number, end: number): Set<number> => {
        if (start === end) {
            return new Set([+s[start]]);
        }

        const results = new Set<number>();
        for (let i = start + 1; i < end; i += 2) {
            const left = calc(start, i - 1);
            const right = calc(i + 1, end);

            left.forEach((l) => {
                right.forEach((r) => {
                    const val = s[i] === '+' ? l + r : l * r;
                    if (val <= MAX) {
                        results.add(val);
                    }
                });
            });
        }

        return results;
    });

    const set = calc(0, s.length - 1);
    const correctResult = calculate(s);

    return answers.reduce((acc, cur) => {
        return acc + (cur === correctResult ? 5 : set.has(cur) ? 2 : 0);
    }, 0);
}

function calculate(s: string): number {
    const stack: Array<string | number> = [s[0]];
    let i = 1;
    while (i < s.length) {
        if (s[i] >= '0' && s[i] <= '9') {
            const peek = stack[stack.length - 1];
            if (peek === '*') {
                stack.pop();
                stack.push(Number(stack.pop()!) * Number(s[i]));
            } else {
                stack.push(s[i]);
            }
        } else if (s[i] === '*') {
            stack.push('*');
        }

        i++;
    }

    let sum = 0;
    stack.forEach((v) => {
        sum += Number(v);
    });

    return sum;
}

function cache<T extends (...args: any[]) => any>(fn: T) {
    const runCache: Record<string, any> = {};

    return ((...args: any[]) => {
        const id = args.join(',');
        if (runCache.hasOwnProperty(id)) {
            return runCache[id];
        }

        runCache[id] = fn.apply(this, args);
        return runCache[id];
    }) as T;
}
