Here the major takeaway is to use Boyer Moore's Majority Vote algorithm in our Segment Tree to find the majority element.
It allows us to find the majority element in a range in O(n) time. 

You can refer to the following link to know more about Boyer Moore Algorithm:
https://en.wikipedia.org/wiki/Boyer%E2%80%93Moore_majority_vote_algorithm
