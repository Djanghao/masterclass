# Intuition
The problem is about generating all structurally unique binary search trees (BSTs) that store values from 1 to n. A binary search tree follows the property that for any given node, values in the left subtree are smaller, and values in the right subtree are larger. The challenge is to generate all such trees while maintaining the BST properties.

# Approach
**1. Recursive Tree Construction:** The approach is based on recursively constructing BSTs by considering each number in the range [1, n] as the root.
   - For each potential root i, the left subtree will be constructed using the numbers from [1, i-1], and the right subtree will be constructed using the numbers from [i+1, n].
   - Recursively generate all possible left and right subtrees for each root.
   - Combine each left subtree with each right subtree to form a tree with the current root i.
   - The base case of the recursion is when min > max, which means no nodes are available to form a tree, so the function returns [null] to indicate an empty tree.

**2. Combination of Trees:** For each possible root i, combine all possible left and right subtrees generated by the recursive calls to create all possible trees with the current root. Append each constructed tree to the result list.
# Complexity
**- Time Complexity:** The time complexity is generally exponential, specifically O(4^n / n^(3/2)). This is related to the Catalan number, which grows rapidly as n increases, representing the number of unique BSTs that can be formed.

**- Space Complexity:** The space complexity is O(4^n / n^(3/2)) for the result list, which stores all the unique trees. Additionally, the recursion stack has a depth of O(n), so the space used by the call stack is O(n).
# Code
```php []
<?php
class Solution {
    public function generateTrees($n) {
        if ($n == 0) {
            return [];
        }
        return $this->generateTreesHelper(1, $n);
    }

    private function generateTreesHelper($min, $max) {
        if ($min > $max) {
            return [null];
        }

        $ans = [];

        for ($i = $min; $i <= $max; $i++) {
            $leftTrees = $this->generateTreesHelper($min, $i - 1);
            $rightTrees = $this->generateTreesHelper($i + 1, $max);

            foreach ($leftTrees as $left) {
                foreach ($rightTrees as $right) {
                    $root = new TreeNode($i);
                    $root->left = $left;
                    $root->right = $right;
                    $ans[] = $root;
                }
            }
        }

        return $ans;
    }
}
?>
```
