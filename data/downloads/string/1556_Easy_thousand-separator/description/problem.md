## Description

Given an integer `n`, add a dot (".") as the thousands separator and return it in string format.

 

**Example 1:**

```

Input: n = 987
Output: &quot;987&quot;

```

**Example 2:**

```

Input: n = 1234
Output: &quot;1.234&quot;

```

 

**Constraints:**

	- `0 <= n <= 2^31 - 1`
